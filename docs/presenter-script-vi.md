# Vietnamese presenter notes

The canonical, slide-by-slide 25-minute Vietnamese presentation script is part of the Hugo workshop: [Vietnamese presentation guide](../content/presentation/_index.md).

It follows the 11-slide deck `EKS_Defense_in_Depth_Vietnamese.pptx` and includes speaking notes, module links, demo cues, timing, sandbox scope, and answers to common questions. The source PowerPoint was read from the presenter's Desktop and is not stored in this repository.
